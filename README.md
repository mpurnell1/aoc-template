# aoc-template
Template repo for Advent of Code

## Quick Start
To begin a new day of AoC puzzles, run `./setup_day.sh` then copy your sample and actual inputs into the corresponding files.
To test your solution on the sample input, run `<solution.py> sample`.
To test your solution on the official puzzle input, run `<solution.py> input`.
Once you have solved puzzle 1 for a given day, run `./solve_day.sh` to create the puzzle 2 solution file based on your existing solution.
